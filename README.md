# CODSOFT Data Analytics Internship – Task 1

## Data Cleaning & Preprocessing

### Dataset
UCI Online Retail II Dataset

The dataset contains two sheets:
- 2009–2010
- 2010–2011

Both sheets were cleaned separately and then combined into one final cleaned dataset.

### Tools Used
- Python
- Pandas
- Jupyter Notebook
- VS Code

### Work Performed
- Imported the dataset using Pandas
- Inspected the dataset structure
- Identified missing values
- Identified and removed duplicate records
- Handled inconsistent and non-sales records
- Removed invalid negative price records
- Corrected data types
- Cleaned text values
- Performed final validation
- Combined the cleaned datasets
- Exported the final cleaned dataset as CSV

### Output
The final cleaned dataset was exported as:

`cleaned_online_retail.csv`
